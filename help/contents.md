# PathwayDesigner Help

PathwayDesigner draws biochemical reaction networks. You can draw a network
with the mouse, or write it as an Antimony model and have it drawn for you.
Either way, the drawing can be saved with the model, as Antimony or as SBML.

## Using this help

Links open other help pages. **Back** returns to the page you came from, and
**Contents** brings you here. The help stays open while you work; drag its
left edge to make it wider or narrower, and close it with ✖.
